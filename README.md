# Job Market Analysis with Adzuna Data

## Project Overview
This repository showcases a Power BI dashboard project built using job market data sourced from the Adzuna API. The dashboard analyzes job postings across countries, industries, and companies to deliver insights into current job trends, salary distributions, and in-demand roles. This project aims to help job seekers, analysts, and recruiters better understand employment patterns and opportunities..

## Visualizations Included
Job Trends by Country & Industry: Track how job demand varies across different countries and job categories.
Top Hiring Companies: View the organizations with the most job postings.
Salary Insights: Analyze max/min salaries and salary ranges by job title, location, and company.
Contract Type Breakdown: Explore distribution between full-time, part-time, contract, and freelance positions.
Interactive Filters: Slicers for filtering by job title, location, salary range, and posting date.

## Data Source
The dataset is powered by the Adzuna API, which aggregates job postings across multiple countries and platforms. The data includes fields such as job title, company name, location, salary details, contract type, and date posted.

## How to Use
To view and interact with the visualizations:
* Download the Job_Dashboard.pbix file from this repository.
* Open the file using Microsoft PowerBI.
* Explore the various reports and visualizations available on the dashboard by clicking through the different tabs.
  
## Tools Used
Microsoft PowerBI: Used for creating and hosting all visualizations and predictive models.
